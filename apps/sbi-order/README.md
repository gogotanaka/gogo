# sbi-order — SBI証券 指値注文の自動発注・rebid・約定通知

Slack botにメンションで指示すると、SBI証券のWebサイトをブラウザ自動化で操作して
現物株の発注・取消・板情報の取得を行う。約定したらSlack/macOSに通知する。

- セットアップ・運用・構成: [docs/setup.md](docs/setup.md)
- 設計判断の経緯・リスク・実画面の知見: [docs/adr/](docs/adr/)
- 今の watch 状況・注文履歴・手動発注: http://localhost:8381 （ローカルweb UI）。
  `SBI_UI_PASSWORD` を設定すれば https://sbi-order.awsm.jp からも**閲覧のみ**
  Basic認証で見られる（発注はローカルかSlackのみ）

## 言語

**rebid** = 買い板の一番上の額（最良買気配）で買い指値を入れること。
watch系コマンドのrebidは、まずその銘柄の未約定注文を取り消してから入れ直す。

## コマンド一覧（Slackで `@gogo <コマンド>`）

| コマンド | 例 | 意味 |
|---|---|---|
| `buy 銘柄 株数 価格` | `buy 3930 300 744` | 一回きりの買い指値注文 |
| `sell 銘柄 株数 価格` | `sell 3930 300 744` | 一回きりの売り指値注文 |
| `watch 銘柄 平均株数 上限価格 平均間隔秒` | `watch 3930 400 760 900` | 場中、平均900秒(±30%ランダム)ごとにrebid。株数も平均400株(±30%ランダム)。最良買気配が上限760円を超えている間は見送り（通知は超えた最初の回だけ）。**解除するまで買い続ける** |
| `unwatch 銘柄` | `unwatch 3930` | watchを解除（未約定の注文は残る） |
| `watch-open buy 銘柄 株数 上限価格` | `watch-open buy 3930 400 760` | **毎営業日**8:59〜9:05の間、20秒ごとにrebid（寄り付き用）。すでに最良買気配に自分の注文が並んでいれば何もしない |
| `unwatch-open 銘柄` | `unwatch-open 3930` | watch-openを解除 |
| `clear-all` | | 「注文中」の注文を全て取消（銘柄指定不可。逆指値などの「待機中」注文は対象外） |
| `book [銘柄]` | `book 3930` | 板情報（気配値・本日出来高）をその場で投稿 |

補足:

- メンションを受信すると、まず👀リアクションで「見た」ことを合図する
- 銘柄コードは**数字4桁のみ**対応（285Aのような英字入りコードは未対応）。株数は売買単位（100株）の倍数で指定する
- 同じ銘柄に watch と watch-open が両方あるときは、**寄り付きの窓（8:57〜9:05）だけ watch-open が優先**し、その間 watch は休止する。**9:05を過ぎれば watch が通常どおり実行される**（watch-open の残注文も次の watch の rebid が取消して置き直す）
- `unwatch` しても未約定の注文は原則残る（rebid実行中の解除では、そのティックが取消済みのことがあり、その場合は通知される）
- `watch` / `watch-open` は銘柄ごとに1つ。同じ銘柄に再設定すると置き換え。
  実行のたびに結果（取消した注文番号・新しい注文・本日約定株数）をSlackに報告する
- **通知のメンション基準**: 板情報の定期投稿とrebidの定常レポートはメンション無し。
  メンションが付くのは人の注意が要るものだけ（要対応・発注失敗・上限超え・
  流動性アラート・再起動による注文取りやめ等）
- **流動性アラート**: watch対象銘柄で、最良売気配から+5円以内の売り数量の合計が
  「watchの平均株数×5」以上になったらメンションで知らせる（まとまった株数を
  一気に買える板の検知。倍率・値幅は `SBI_LIQ_ALERT_MULT` / `SBI_LIQ_ALERT_RANGE_YEN`
  で調整可。条件を満たしている間は繰り返さない）
- watchのrebidは**その銘柄の未約定注文を全部**取り消す。watch対象の銘柄に `buy` で
  出した手動注文も次のrebidで消える
- 1注文の見積金額が `SBI_MAX_ORDER_VALUE_YEN` を超える発注は自動的に数量を下げるか拒否する
- 板情報は営業日の8:00から10分ごと（8:00, 8:10, …）に自動でメンション付き投稿される
- 発言者が許可ユーザー（`SLACK_MENTION_USER`）でないメンションは実行されない
