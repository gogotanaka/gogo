## 技術メモ（スニダン購入フロー）

- カートに複数の中古アイテムを追加可能（上限10点っぽい）
- SOLD商品はカートに入ったままだが、レジページには表示されず自動除外される
- カートの削除ボタンは ref で特定しようとしたが、ARIA refとDOM順序がズレることがあった
- JS で `.is-sold-label` クラスを探しても全アイテムにあるので使えない
- JS で `img[alt="SOLD"]` もすべてのアイテムに存在する（非表示のものも含む）
- 実用的には「レジへ進む」を押すとSOLD品は自動除外されるのでOK
- カートに追加するボタンは `document.querySelector('[class*="add-to-cart"], [class*="cart"], button[class*="buy"]')` でヒットする
- 追加後のボタンテキストが「カート追加済」になればOK
- 3DS認証メールは `ic` ワークスペース `C0AHPS78N0M` に届く
- Slackページの iframe src の末尾（最新）が最新メール
